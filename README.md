# 🌙 Well - Done

**나의 근무 스케줄에 맞춰 웰니스 루틴을 설계하는 AI 서비스**

교대 근무자(간호사, 생산직, 서비스직 등)를 위한 맞춤형 웰니스 루틴 추천 & 회복 관리 서비스

</div>

---

## 서비스 소개

`Well Done`은 **불규칙한 교대 근무로 자기관리가 어려운 사람들**을 위한 웰니스 루틴 서비스입니다.

일반적인 건강관리 앱은 "매일 아침 7시 기상, 매일 저녁 9시 취침"처럼 고정된 하루를 전제로 하지만, 3교대 근무자에게는 통하지 않습니다. Well Done은 사용자의 **실제 근무 스케줄(Day/Evening/Night/Off)을 입력받아, AI가 그 스케줄에 맞춘 웰니스 루틴을 1주일 단위로 제안**합니다.

- 출근 전/퇴근 후/취침 전 등 **근무 컨텍스트별로 다른 루틴**을 추천
- 매달 자동으로 생성되는 **AI 웰니스 리포트**로 지난달을 돌아보고, 다음 달의 회복 포인트를 미리 안내
- 같은 근무조(Day/Evening/Night/Off)끼리 소통할 수 있는 **듀티 라운지**로 동료애와 동기부여 제공

##  주요 화면 및 기능 

- **온보딩 (onboard)**
  - 로그인 페이지 전 프로젝트의 로고 보여주기
  - 사용자의 버튼 클릭에 따라 로그인 또는 회원 가입 페이지로 이동
 
- **로그인 (login)**
  - 사용자의 아이디, 비밀번호 입력을 통한 회원 가입 되어 있는 계정에 로그인
  - 또는 회원 가입이 필요한 사용자를 위해 하단의 버튼으로 회원 가입 페이지로 이동

- **회원가입 (signup)**
  - 이름, 사용할 아이디, 비밀번호 입력을 통한 회원가입
  - 이미 계정이 있는 경우 로그인 페이지로 이동 가능한 버튼 제공

- **홈 페이지 (home)**
  - 원형 진행도 바를 통한 실시간 웰니스 게이지 및 점수 시각화
  - 당일 예정된 오늘의 루틴 리스트 확인 및 관리 기능
  - 설정 기능을 통한 스케줄표 업데이트 및 생성 기능

- **마이 페이지 (mypage)**
  - 주간 웰니스 루틴 수행 내역 기능
  - 지난 달 웰니스 수행 내역 등이 포함 된 요약 리포트 기능

- **듀티 라운지 (challenge)**
  - 웰니스 포인트를 통해 구매할 수 있는 웰니스 아이템 리스트를 보여주는 리워드 샵 박스
  - 같은 팀 타입 간의 익명 휘발성 대화 ( 최대 3건 노출)
  - 해당되는 팀 타입(데이, 나이트, 오프, 이브닝)에 따른 전체 평균 진행도를 게이지로 시각화

- **스케쥴표 기반 ai 웰니스 루틴 생성(routine)**
  - 교대 근무표 등의 스케줄 표 제작 기능
  - 스케줄 표 사진, 웰니스 카테고리, 질문사항을 받아 AI를 통한 웰니스 루틴 생성
 
- **ai 기반 루틴 생성 결과 페이지(result)**
  - 루틴 생성 페이지의 데이터를 통해서 생성된 AI의 답변 결과를 보기좋게 정리
  - 결과가 마음에 들지 않을 경우 사용가능한 다른 루틴으로 재추천 기능

## 📌 프로젝트 배경

해커톤이라는 제한된 시간 속에서, **교대 근무자의 사용자 경험(UX)을 직관적으로 전달하는 것**에 집중했습니다.
- 복잡한 3교대 스케줄과 캘린더 UI를 빠르고 안정적으로 구현하기 위해 **React와 Vite** 환경을 신속하게 구축
- 교대 근무자의 가독성과 몰입도를 높이기 위해 **Swiper**와 **Framer Motion**을 활용한 모바일 최적화 UI 및 애니메이션 적용
- 날짜 계산(`Day.js`)과 스케줄표 이미지 캡처/저장(`html2canvas`) 등 사용자 편의 기능을 실속 있게 구현하여 완성도 보완
